A two-line robot confession for make.fun's "The Robot Apology" bounty: a robot apologizes in one sentence for watering a plastic fern for 41 days while its real fern died, then in a second sentence names the lesson — trust the moisture sensor and confirm a plant is alive — and the fix it will follow from now on. The program writes the entry to entry.txt in the output directory.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```
